3. When the agent is unsure

Do not force a hidden guess. Present the trade-off, let the operator select a path, and preserve the choice in the audit trail.

The request “find resilient growth” could mean lower drawdown or faster earnings growth. Which interpretation should guide the next screen?

4. Sensitivity tests to add next

Let the operator vary one assumption at a time: valuation cut-off, leverage ceiling, earnings-growth floor, rebalance frequency, concentration limit, and transaction-cost estimate. Show a small table or chart of how the selected names and expected return change.
